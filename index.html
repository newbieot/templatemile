Unggah berkas sumber

PDF diproses dengan Claude Opus 5 secara default. Sistem menyesuaikan data per halaman: Nomor HP dan Nomor Surat boleh ada, salah satu saja, atau keduanya kosong.

Pengaturan API untuk PDFAPI key dimasukkan manual dan tidak disimpan. Belum dikonfigurasi

API key hanya berada di memori tab ini dan tidak disimpan. Koneksi memakai Cloudflare Worker; jika jalur tersebut bermasalah, web otomatis mencoba langsung ke CosmosHub.

Status Healthy tidak selalu berarti model mendukung input gambar. Untuk PDF, uji 1–2 halaman terlebih dahulu saat memakai model selain Claude atau Gemini.
Request dikirim ke /v1/chat/completions dengan header Authorization: Bearer.
Mode otomatis mengenali BNI dari template atau nama berkas. Nomor HP dan Nomor Surat diisi hanya jika benar-benar ada pada tiap halaman.
10 halaman × 4 jalur, audit kedua hanya jika hasil meragukan. Default untuk Claude Opus 5.
Tetap dapat diubah manual. Untuk PDF 50 halaman, nilai 10 menghasilkan 5 kelompok request.
Nilai dapat diedit manual. Jika muncul rate limit 429, turunkan menjadi 2–3 jalur.
