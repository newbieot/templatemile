MILE CN23 HELPER 0.2.9

KOMPATIBILITAS BROWSER
Chrome 88 ke atas, termasuk Chrome 109.0.5414.120 pada Windows 7 32-bit.
Paket yang sama dapat dipakai pada Chrome 32-bit dan 64-bit.

MEMPERBARUI VERSI LAMA
1. Saat tidak ada transaksi yang sedang diproses, ekstrak ZIP 0.2.9 ke folder
   ekstensi lama dan timpa file lama, termasuk manifest.json.
2. Buka chrome://extensions, klik Reload/Muat ulang pada Mile CN23 Helper.
   Versi harus tertulis 0.2.9.
3. Buka form CN23 kosong dan muat ulang tab Mile:
   https://expos.mile.app/new-transaction-custom
4. Antrean dari 0.2.5 sampai 0.2.8 tetap tersimpan. Bila berhenti karena selisih kode pos,
   tekan Start untuk melanjutkan; baris selesai tidak diulang. Tidak perlu Reset.
   Cache 0.2.4 dan versi sebelumnya otomatis dibersihkan. Jika antrean kosong,
   upload Excel yang ingin diproses, lalu klik Start sekali.

INSTALASI PERTAMA
1. Ekstrak ZIP ke folder tetap yang langsung berisi manifest.json.
2. Buka chrome://extensions, aktifkan Developer mode/Mode developer.
3. Pilih Load unpacked/Muat yang belum dikemas, pilih folder hasil ekstrak.
4. Pin Mile CN23 Helper dari ikon puzzle Chrome.
5. Login Mile pada Chrome yang sama, buka form CN23 kosong, lalu muat ulang
   tab jika sudah terbuka sebelum instalasi.

PEMAKAIAN HARIAN
1. Capture label di Mile Camera, Proses AI, lalu unduh Antrean CN23 (.xlsx).
   Excel Lokal Batam dan Antrean CN23 tetap terpisah untuk batch campuran.
2. Klik ikon ekstensi pada tab Mile. Menu muncul di halaman tersebut:
   Upload Excel, Start/Jeda, dan Reset.
3. Upload Antrean_CN23...xlsx, sheet CN23_ANTREAN, lalu klik Start sekali.
4. Korporat: Kode Pelanggan diisi dan Enter ditekan otomatis. Ekstensi
   menunggu nama, telepon, dan alamat pengirim dari Mile selesai dimuat.
5. Pengisian, hitung PDRI, Cash untuk ritel atau Invoice/CREDIT sesuai Excel
   korporat, dan tombol Selesai diproses otomatis.
6. Saat Mile masuk ke daftar transaksi, tab utama langsung membuka form CN23.
   Ekstensi menunggu seluruh kolom form baru siap dan kosong, lalu mengisi
   data kedua. Alur yang sama berjalan hingga seluruh antrean selesai.
   Tab cetak tidak dibaca dan tidak menentukan kelanjutan antrean.
7. Panel muncul kembali setelah navigasi. Tidak perlu menekan Start lagi.
8. Setelah semua data selesai, pesan hijau tampil selama 5 detik. Tombol ×
   menutupnya langsung. Pesan lama tidak muncul lagi saat halaman dimuat ulang.
   Status selesai tetap tersimpan di panel; kiriman selesai tidak diulang.
   Hasil transaksi dan pencetakan dikelola melalui Daftar Transaksi Mile.
9. Untuk mengganti Excel, klik Reset, Upload Excel baru, lalu Start.
   Reset menghentikan proses dan menghapus seluruh data antrean tersimpan.
   File yang sama dapat di-upload lagi; semua barisnya menjadi antrean baru.

GANGGUAN
- Jika pengisian gagal, penyebab tampil pada panel. Perbaiki penyebabnya
  dan gunakan Start untuk mencoba ulang pengisian yang belum dikirim.
- Jika Mile tidak berpindah setelah Selesai, periksa transaksi di Mile
  sebelum mengulang kiriman tersebut. Reset tetap dapat mengosongkan data.

DOKUMEN / jumlah 1 / nilai Rp20.000 / berat 0,2 kg / ID /
EN-Envelope / IMEI 0 dan 0 / dimensi 0 / NON-COD.
Asuransi, service, referensi, dan instruksi mengikuti Excel.
Untuk Pos Express, pilih PE pada Kode layanan saat menyiapkan hasil kamera,
sebelum mengunduh Excel antrean.
Kode zona mengikuti pilihan Mile.
Kode pos dan kode zona yang dikunci Mile selalu dipakai setelah wilayah cocok,
meskipun berbeda dari Excel. Aturan ini berlaku untuk seluruh tujuan.

PENGUJIAN 0.2.9
Satu Start diuji untuk tiga kiriman: Cash, Invoice, lalu CREDIT. Tidak ada
tab cetak dalam pengujian. Nama penerima, referensi, metode pembayaran,
dan pengirim korporat diperiksa saat masing-masing tombol Selesai ditekan.
Uji mencakup reload penuh, navigasi dalam dokumen yang sama, pesan siap
yang terlewat, dan data kedua ketika form baru sudah terload. Form berikutnya
ditunggu sampai semua kolom termasuk ref_no siap; salinan tersembunyi dari
form lama diabaikan. Panel setelah navigasi, Reset, upload ulang, dan
pembersihan cache lama diuji. Uji memakai simulasi DOM/service worker dan ekstensi terpasang pada
Chromium 88.0.4324.0 serta 109.0.5414.0 32-bit dengan form uji lokal.
Pengujian tidak membuat transaksi Mile produksi. Windows 7 tidak diuji langsung.
Perbedaan beberapa kode pos dan kode zona diuji untuk ritel dan korporat.
Data kedua dengan kode pos Mile berbeda tetap selesai, lalu data ketiga
berjalan otomatis. Kemajuan 0.2.5 dan pengulangan hanya baris gagal juga diuji.
PE juga diuji melalui satu Start untuk tiga kiriman: ritel Cash, korporat
Invoice, dan korporat CREDIT. Pada tiap submit, kode layanan PE diperiksa,
termasuk saat berpindah ke form kedua dan ketiga setelah reload penuh.
Pesan selesai diuji otomatis hilang setelah 5 detik, ditutup dengan ×,
serta tidak tampil kembali setelah reload. Uji PE memakai simulasi;
transaksi PE nyata pada Mile belum diuji.

Kompatibilitas API callback Chrome lama diuji sampai tiga kiriman PE selesai
dari satu Start: Cash, Invoice, lalu CREDIT, termasuk pengisian form kedua
dan ketiga setelah reload. Fallback UUID diuji tanpa randomUUID.

Data antrean tersimpan lokal di Chrome. Tidak meminta password/API key.
Permission storage/alarms, akses situs hanya https://expos.mile.app/*.
