MILE CN23 HELPER 0.2.2

MEMPERBARUI VERSI LAMA
1. Saat tidak ada transaksi yang sedang diproses, ekstrak ZIP 0.2.2 ke FOLDER
   ekstensi lama dan timpa file lama, termasuk manifest.json. Jangan uninstall.
2. Buka chrome://extensions, klik Reload/Muat ulang pada Mile CN23 Helper.
   Versi harus tertulis 0.2.2. Riwayat ID kiriman dan resi tetap tersimpan.
3. Simpan pekerjaan, lalu muat ulang tab Mile agar script terbaru aktif.
   Jangan muat ulang transaksi yang belum pasti sesudah tombol Selesai.

INSTALASI PERTAMA
1. Ekstrak ZIP ke folder tetap yang langsung berisi manifest.json.
2. Buka chrome://extensions, aktifkan Developer mode/Mode developer.
3. Pilih Load unpacked/Muat yang belum dikemas, pilih folder hasil ekstrak.
4. Pin Mile CN23 Helper dari ikon puzzle Chrome.
5. Login Mile pada Chrome yang sama, buka form CN23 kosong:
   https://expos.mile.app/new-transaction-custom
6. Jika tab dibuka sebelum instalasi, simpan pekerjaan lalu muat ulang tab.

PEMAKAIAN HARIAN
1. Capture label di Mile Camera, Proses AI, lalu unduh Antrean CN23 (.xlsx).
   Campuran tetap menghasilkan Excel Lokal Batam dan Antrean CN23 terpisah.
2. Pada tab Mile yang sudah login, klik ikon ekstensi. Menu langsung muncul
   pada halaman tersebut: Upload Excel dan Start. Tidak membuka tab panel baru.
3. Upload file Antrean_CN23...xlsx, sheet CN23_ANTREAN, lalu klik Start sekali.
4. Korporat: ekstensi mengisi Kode Pelanggan, Enter, lalu menunggu nama,
   telepon, dan alamat pengirim muncul. Pengirim dari Mile dipertahankan.
5. Form, hitung PDRI, Cash untuk ritel / Invoice atau CREDIT sesuai Excel
   korporat, dan Selesai diproses otomatis.
6. Ketika daftar transaksi muncul, tab utama kembali ke form CN23.
   Resi pada tab baru dicocokkan sebelum transaksi berikutnya berjalan.
   Tidak perlu memilih pembayaran atau menekan Start lagi setiap kiriman.
7. Semua selesai: pesan hijau tampil. Resi tetap dapat dicetak manual di Mile.
8. Ingin mengganti Excel: klik Reset, lalu Upload Excel baru dan Start.
   Reset menghentikan proses lama. ID kiriman yang sudah berhasil tetap
   dicatat dan dilewati jika ada lagi di file baru. Panel tanpa menu unduh hasil.

GANGGUAN
- Kegagalan sebelum Selesai: kesalahan tampil di menu; setelah penyebabnya
  diperbaiki, Start mencoba ulang pada form baru yang kosong.
- Gangguan setelah Selesai: hasil belum pasti ditahan untuk mencegah resi
  ganda. Periksa transaksi di Mile sebelum mengulang atau mengganti antrean.
  Panel pemulihan versi lama tetap disertakan untuk mencatat resi yang
  sudah dipastikan milik kiriman aktif. Panel itu bukan menu pemakaian harian.
- Jangan menghapus data ekstensi atau mengganti profile Chrome. ID selesai mencegah pemrosesan ganda.
- Tab resi lama/cetak ulang tidak dianggap bukti sukses transaksi baru.

DOKUMEN / jumlah 1 / nilai Rp20.000 / berat 0,2 kg / ID /
EN-Envelope / IMEI 0 dan 0 / dimensi 0 / NON-COD.
Asuransi, service, referensi, dan instruksi mengikuti Excel.
Kode zona mengikuti pilihan Mile, tidak ditebak dari kode pos.

PENGUJIAN
Form CN23, pencarian KATEMAN 29255, dan struktur dialog pembayaran
select-payment diperiksa pada Mile yang terbuka. Dropdown pembayaran
dibuka melalui wrapper dan dicoba ulang ketika klik pertama diabaikan
transisi dialog. Daftar yang dipindahkan ke body tetap dikenali.
Form berikutnya ditunggu sampai seluruh kolom termasuk ref_no siap dan
stabil, dengan mengabaikan salinan tersembunyi dari form sebelumnya.
Sinyal siap halaman pertama tidak dipakai untuk kiriman berikutnya;
kiriman berikutnya menunggu resi cocok dan form baru yang kosong.
Upload workbook, Cash/Invoice/CREDIT, Enter pelanggan, resi tab baru,
redirect daftar transaksi, antrean berikutnya dan notifikasi diuji melalui
simulasi DOM dan service worker, termasuk klik pertama diabaikan,
dropdown di luar dialog, dan ref_no yang terlambat muncul.
Uji integrasi tiga kiriman menggabungkan script form, pengelola antrean,
dan pembaca resi: satu Start, Cash lalu Invoice lalu CREDIT, form baru,
tiga submit tunggal dan satu notifikasi selesai.
Submit produksi dengan ekstensi Chrome
terpasang belum dilakukan. Perubahan tampilan Mile dapat memerlukan adaptasi.

Data antrean lokal di Chrome. Tidak meminta password atau API key.
Permission tetap storage/alarms, terbatas pada Mile dan halaman print resi.
Panduan resmi Chrome:
https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-an-unpacked-extension

VERSI 0.2.2
Panel hanya Upload Excel, Start/Jeda, Reset. Pemeriksaan form kosong
berulang setiap detik dan probe otomatis memulihkan laporan siap yang
terlewat. Navigasi Mile dalam dokumen yang sama didukung. Versi panel
mengikuti versi script. Resi tetap menjadi bukti keberhasilan internal.
