01 · Mile Camera

Dari label alamat menjadi Excel

Pasang atau perbarui APK di HP
  1. Tekan Unduh APK Mile Camera dari HP Android, lalu buka file APK yang diunduh.
  2. Jika Android meminta izin, izinkan pemasangan dari browser atau pengelola file yang dipakai untuk membuka APK.
  3. Pilih Instal atau Perbarui. Untuk memperbarui aplikasi lama, langsung pasang APK ini tanpa menghapus aplikasi.
  4. Buka Mile Camera, login dengan akun terdaftar, lalu izinkan akses kamera.
Capture dan ekspor hasil
  1. Pilih tujuan Batam, CN23 Dokumen Luar Kota, atau Campuran Batam + Luar Kota sebelum mulai capture.
  2. Tekan Mulai capture. Letakkan label sehingga seluruh alamat terlihat. Ketuk teks untuk fokus bila perlu, lalu tekan shutter.
  3. Ulangi untuk label berikutnya. Periksa galeri dan ambil ulang foto jika teksnya kabur, lalu tekan Selesai.
  4. Di halaman hasil, pilih template pelanggan atau isi pengaturan pengirim dan layanan. Jalankan Proses AI jika belum berjalan.
  5. AI mencocokkan desa/kelurahan atau kecamatan dengan database kode pos. Periksa bagian yang belum terbaca atau tujuan yang masih memiliki beberapa kode pos berbeda.
  6. Untuk luar Batam, unduh Antrean CN23. Untuk Batam, unduh Excel Lokal Batam. Mode Campuran menyediakan dua file terpisah.

Hasil kamera yang sudah tersimpan juga dapat dibuka melalui Log Kamera di web Mile pada komputer.

02 · Ekstensi Chrome

Satu Start untuk seluruh antrean CN23

Instalasi pertama di komputer
  1. Unduh ZIP Ekstensi Chrome, lalu ekstrak ke folder tetap. Folder yang dipilih harus langsung berisi manifest.json.
  2. Buka Chrome, ketik chrome://extensions di bilah alamat, lalu tekan Enter.
  3. Aktifkan Developer mode / Mode developer, pilih Load unpacked / Muat yang belum dikemas, lalu pilih folder hasil ekstrak.
  4. Dari ikon puzzle Chrome, pin Mile CN23 Helper agar mudah dibuka.
  5. Login Mile pada Chrome yang sama, buka Transaksi CN23, lalu muat ulang tabnya. Pastikan versi ekstensi 0.2.7.
Upload Excel dan jalankan antrean
  1. Siapkan file Antrean CN23 dari Mile Camera atau web Mile. Gunakan file luar kota, dengan sheet CN23_ANTREAN.
  2. Pada tab Transaksi CN23 yang kosong, klik ikon ekstensi. Menu Upload Excel, Start/Jeda, Reset muncul di halaman tersebut.
  3. Tekan Upload Excel, pilih file antrean, lalu tekan Start sekali.
  4. Untuk korporat, ekstensi mengisi Kode Pelanggan dan menekan Enter, lalu memakai pengirim yang muncul dari Mile. Untuk ritel, pengirim mengikuti Excel.
  5. Ekstensi mengisi form dan detail dokumen, menghitung PDRI, memilih Cash untuk ritel atau Invoice/CREDIT sesuai Excel korporat, lalu menekan Selesai.
  6. Setelah Mile masuk ke daftar transaksi, ekstensi membuka form CN23, menunggu kolom siap, lalu mengisi data kedua dan seterusnya. Biarkan tab utama terbuka sampai pesan selesai muncul.

Pesan hijau selesai otomatis hilang setelah 5 detik dan dapat ditutup dengan ×. Status selesai tetap tersedia di panel ekstensi.

Kode pos dan kode zona mengikuti Mile. Perbedaan dengan Excel tidak menghentikan transaksi setelah wilayah tujuan cocok. Tab cetak tidak dibaca atau ditunggu; pencetakan dapat dilakukan sendiri dari Daftar Transaksi Mile.

03 · Pembaruan & antrean

Perbarui ekstensi atau ganti Excel

Memperbarui ekstensi lama
  1. Saat antrean sudah berhenti, unduh ZIP terbaru dan timpa file di folder ekstensi lama.
  2. Buka chrome://extensions, klik Reload / Muat ulang. Pastikan versi 0.2.7 dan hanya satu Mile CN23 Helper yang aktif.
  3. Buka form CN23, lalu muat ulang tab Mile agar script terbaru digunakan.
  4. Jika versi 0.2.5 berhenti karena perbedaan kode pos, tekan Start untuk melanjutkan. Kemajuan tetap tersimpan; baris yang sudah selesai tidak diulang. Tidak perlu Reset atau upload ulang.
Kapan memakai Jeda dan Reset?

Jeda menghentikan kelanjutan antrean. Jika pengisian yang belum dikirim terhenti, Start membuka form kosong untuk mencoba kembali baris tersebut.

Reset menghentikan proses dan menghapus seluruh antrean tersimpan. Setelah itu, pilih Excel baru dan tekan Start. Semua baris file yang di-upload menjadi antrean baru.

Untuk melanjutkan antrean yang masih tersimpan, gunakan Start. Gunakan Reset hanya ketika ingin mengganti antrean.

Kiriman lokal Batam dan luar Batam tercampur

Pilih Campuran Batam + Luar Kota sebelum capture atau proses AI. Hasil dikelompokkan otomatis. Unduh Excel Lokal Batam untuk unggah lokal, dan Antrean CN23 untuk ekstensi. Keduanya tetap tersendiri.
